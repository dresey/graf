## ⚠️ Что нужно для доступа из интернета (публичный HTTPS):

### 1. Установить Tailscale

Скачай и установи с официального сайта:
```
https://tailscale.com/download/windows
```

После установки:
- Войди в свой Tailscale аккаунт
- Перезапусти PowerShell/cmd

### 2. Включить Tailscale Funnel (публичный HTTPS)

Открой PowerShell **от имени администратора** и выполни:
```powershell
tailscale funnel 3000
```

Получишь URL вида `https://твой-хост.ts.net/`

### 3. Обновить конфигурацию фронтенда

Открой файл `server-config.js` и замени на реальный URL:
```javascript
window.GRAFIK_API_URL = 'https://твой-реальный-адрес.ts.net';
```

### 4. Обновить CORS в .env

Добавь свой Tailscale URL в `.env`:
```
ALLOWED_ORIGINS=https://dresey.github.io,https://твой-хост.ts.net
```

### 5. Перезапустить сервер

```cmd
taskkill /F /IM node.exe
start-server.bat
```

### 6. Залить на GitHub Pages

Закоммить и запушить файлы:
- `index.html`
- `app.js`
- `styles.css`
- `server-config.js` (с правильным URL!)

**НЕ коммить:** `.env` (он уже в `.gitignore`)

## 🐛 Решение проблем

### Не запрашивается токен:
- Проверь, что в `server-config.js` указан правильный URL
- Открой консоль браузера (F12) и проверь ошибки
- Убедись, что API-сервер запущен: `curl http://localhost:3000/api/health`

### Данные не синхронизируются между устройствами:
- Убедись, что оба устройства используют **один и тот же API URL**
- Проверь, что в `.env` указаны все ALLOWED_ORIGINS
- Открой консоль браузера и проверь Network → найди запросы к `/api/state`
- Перезапусти API-сервер с новым `.env`

### Ошибка CORS:
- Добавь источник (origin) в `.env` → `ALLOWED_ORIGINS`
- Перезапусти API-сервер
- Пример: `ALLOWED_ORIGINS=http://localhost:8080,http://192.168.1.92:8080`

### Порт занят:
```cmd
netstat -ano | findstr :3000
taskkill /PID <номер_процесса> /F
```
