## ⚠️ Что нужно сделать вручную:

### 1. Установить Tailscale (для публичного доступа)

Скачай и установи с официального сайта:
```
https://tailscale.com/download/windows
```

После установки:
- Войди в свой Tailscale аккаунт
- Перезапусти PowerShell/cmd

### 2. Включить Tailscale Funnel (публичный HTTPS)

Открой PowerShell **от имени администратора** и выполни:
```powershell
tailscale funnel 3000
```

Это создаст публичный HTTPS URL вида `https://dresee.tail7ee3bb.ts.net/`

### 3. Обновить конфигурацию фронтенда

После запуска Funnel получишь реальный URL. Открой файл `server-config.js` и замени URL на свой:
```javascript
window.GRAFIK_API_URL = 'https://твой-реальный-адрес.ts.net/';
```

### 4. Залить на GitHub Pages

Закоммить и запушить файлы:
- `index.html`
- `app.js`
- `styles.css`
- `server-config.js` (с правильным URL!)

**НЕ коммить:** `.env` (он уже в `.gitignore`)

## 🎯 Управление сервером

**Остановить сервер:**
```cmd

```

```cmd

```
(или двойной клик на `start-server.bat`)

**Проверить статус:**
```cmd
netstat -ano | findstr :3000
```
