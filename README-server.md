# Общая база графика на ноутбуке (Windows)

Сайт сейчас хранит данные в браузере. Для синхронизации подготовлен небольшой API-сервер без дополнительных npm-зависимостей. Он хранит весь график в `data/schedule.json` на ноутбуке и принимает запросы только с сайта `https://dresey.github.io` (а также с GitHub Pages origin, который вы добавите для локальной разработки).

## Безопасность и доступ

- Для входа используется один пароль команды. Не отправляйте его в чат и не храните в GitHub.
- Все `/api/state` запросы требуют временную сессию; пароль напрямую не сохраняется на устройстве после входа.
- После перезапуска сервера сессии сбрасываются, сотрудникам потребуется войти снова.
- Публичный Funnel публикует API в интернете. В коде сайта нельзя размещать секреты или пароли.
- `data/schedule.json` исключён из Git и должен резервно копироваться отдельно.

## Настройка на ноутбуке

1. Установите актуальную LTS-версию Node.js с https://nodejs.org/en/download/ и Tailscale с https://tailscale.com/download.
2. Скопируйте проект в постоянную папку на ноутбуке, например `C:\grafik-server`.
3. Откройте PowerShell в этой папке.
4. Придумайте уникальный пароль команды длиной не менее 12 символов. Не используйте пароль от почты/другого сервиса и не присылайте его в чат.
5. Запустите подготовленный скрипт в PowerShell:

   ```powershell
   $env:ALLOWED_ORIGINS = 'https://dresey.github.io'
   powershell -ExecutionPolicy Bypass -File .\run-server.ps1
   ```

   Замените `USERNAME` на имя владельца репозитория GitHub, если оно отличается от `dresey`. Введите придуманный пароль в скрытом приглашении. Оставьте это окно открытым, пока сервер работает. Второе окно PowerShell используйте для Funnel. Скрипт не записывает пароль в проект.

6. В третьем окне PowerShell проверьте локальный API:

   ```powershell
   Invoke-RestMethod http://127.0.0.1:3000/api/health
   ```

   Ожидаемый результат: `ok : True`.

## Публичный HTTPS через Tailscale Funnel

1. Войдите в Tailscale на ноутбуке и откройте Admin Console → **Access controls** → **Funnel** → **Add Funnel to policy**.
2. В PowerShell выполните:

   ```powershell
   tailscale funnel 3000
   ```

3. Если Tailscale предложит подтвердить Funnel или включить HTTPS, следуйте ссылке и подтвердите настройку в собственной учётной записи. Команда покажет URL вида `https://имя.хвост.ts.net`. Скопируйте его. Адрес доступен публично, хотя изменения данных защищены паролем.
4. В файле `server-config.js` укажите выданный URL в `window.GRAFIK_API_URL`, например `window.GRAFIK_API_URL = 'https://имя.хвост.ts.net';`, затем отправьте изменение в GitHub Pages. URL не является секретом; пароль туда не помещайте.
5. После публикации откройте сайт с телефона через мобильный интернет, введите URL API и пароль команды в окне входа. Сделайте отметку, затем проверьте, что она видна на другом устройстве.

Актуальные требования и ограничения Funnel: https://tailscale.com/docs/features/tailscale-funnel. Funnel требует HTTPS/MagicDNS, использует поддерживаемые Tailscale порты и не обещает неограниченную пропускную способность.

## Важное ограничение текущей подготовки

Код сервера подготовлен, но его нельзя сделать рабочим снаружи, пока он не запущен на вашем ноутбуке, не включён Funnel и не известен URL `*.ts.net`. Изменение файлов проекта само по себе не запускает сервер и не публикует его. Общие данные следует впервые настроить уже после публикации; локальные отметки из разных браузеров автоматически объединить нельзя. Файл `.env.example` только показывает настройки и автоматически не читается сервером; пароль вводится через `run-server.ps1`.
